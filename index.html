What's new
16 August 2026
  • Search no longer matches on series names — just titles, authors, notes, quotes, and ISBN
  • Ornaments only appear where you've chosen to add one to a book — nothing shows up on its own any more
  • You can now drag an ornament onto a different book to move it there
  • Typing an ISBN in by hand now actually looks it up, and tells you if it can't find it
  • "Would you recommend it?" is now "What did you think?" — pick as many as apply
  • The "special copy" tick-box now has its own list of reasons to choose from
  • New "📋 Duplicate copy" button lets you copy a book as a different format (say, physical → Kobo) without retyping everything
  • Kobo and Audiobook shelves now have their own colour, so they're easy to tell apart from your main shelf
  • Added an "Own it, read it" status and a "Dark Romance" genre
  • Backing up and restoring now shows you the date, size, and book count before anything gets replaced
  • Should feel noticeably snappier, especially going back to the main shelf
About
🐉 A dragon's hoard for books — shelves by genre, a Kobo shelf, a wishlist, and barcode scanning to add books fast.

Everything is stored only on this device — no account, no cloud — so back it up from Settings now and then.
